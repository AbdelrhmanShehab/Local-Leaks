# Local Leaks 🛍️

Local Leaks is an e-commerce platform designed for local brands, offering a seamless shopping experience with modern UI/UX and essential features.

## 🚀 Features
- **User Authentication**: Login & Register system
- **Product Management**: Browse and filter products by category, brand, and price
- **Advanced Search**: Quick search functionality
- **Cart & Checkout**: Smooth shopping experience
- **Admin Dashboard**: Add/remove products easily
- **Responsive Design**: Fully optimized for all devices

## 🛠️ Tech Stack
- **Frontend**: React.js, CSS Modules
- **State Management**: useState, useEffect
- **Routing**: React Router
- **Icons & UI**: FontAwesome, Custom Components

## 📦 Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/local-leaks.git

# Navigate to the project folder
cd local-leaks

# Install dependencies
npm install

# Start the development server
npm start
```
